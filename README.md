# WhatsApp AI Auto-Responder

A Python bot that automatically replies to WhatsApp messages with natural, human-sounding responses generated by a cloud AI model. It uses **Selenium** to control WhatsApp Web and the **OpenRouter API** to generate replies, so no local AI model or GPU is needed and RAM usage stays low.

## How It Works

1. Launches Chrome through Selenium and opens WhatsApp Web.
2. You scan the QR code once to log in.
3. The bot continuously watches for chats with unread message badges.
4. It opens the chat, reads the latest incoming message, and sends it to an OpenRouter model (DeepSeek Chat V3 by default).
5. The model returns a short, casual reply matching the tone of the message.
6. The bot waits a random "thinking" delay, then types the reply character by character with human-like timing and sends it.

## Features

- **Cloud-powered replies** through OpenRouter, with easy model switching (DeepSeek, Qwen, Llama, etc.)
- **Human-like behavior** with randomized thinking delays, typing speed, and pauses
- **Casual tone** with short replies and occasional emojis, controlled by an editable system prompt
- **Fallback responses** if the API fails or times out
- **Duplicate protection** so the bot doesn't reply twice to the same message
- **Auto-managed ChromeDriver** through `webdriver-manager`

## Requirements

- Python 3.9 or newer
- Google Chrome
- A free [OpenRouter](https://openrouter.ai) API key

## Installation

```bash
pip install selenium webdriver-manager requests
```

## Configuration

Never hard-code your API key in the script. Set it as an environment variable instead.

**Windows (PowerShell):**
```powershell
$env:OPENROUTER_API_KEY="your-key-here"
```

**macOS / Linux:**
```bash
export OPENROUTER_API_KEY="your-key-here"
```
